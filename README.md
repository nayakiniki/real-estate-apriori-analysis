# real-estate-apriori-analysis
This project uses the Apriori algorithm to analyze real estate property data and identify common combinations of features preferred by buyers. It studies factors like BHK type, budget range, location, and amenities to understand demand patterns. A simple frontend is also included.

# Real Estate Demand Analyzer Using Apriori

## Overview

This project focuses on analyzing real estate property data to understand buyer demand patterns using the Apriori algorithm. In the real estate market, buyers usually consider multiple features together when selecting a property, such as BHK type, budget range, location advantages, and amenities. Instead of making assumptions, this system uses data mining techniques to discover meaningful patterns from actual property listings.

The goal is to identify combinations of features that frequently occur together and understand how they influence demand.



## Problem Statement

Real estate developers and agents often rely on intuition to decide what type of properties to build or promote. However, market demand is influenced by multiple factors working together. This project aims to analyze property data and uncover frequent feature combinations that reflect real buyer preferences.



## Objectives

* Collect and preprocess real estate property data
* Convert property attributes into a format suitable for association rule mining
* Apply the Apriori algorithm to generate frequent itemsets
* Evaluate rules using support, confidence, and lift
* Visualize discovered demand patterns through a simple frontend



## Technologies Used

* Python
* Pandas
* Mlxtend (Apriori implementation)
* Flask or FastAPI (Backend API)
* HTML/CSS/JavaScript or React (Frontend)
* Matplotlib or Chart libraries for visualization


## How It Works

1. The dataset containing property listings is uploaded.
2. Data is cleaned and converted into categorical values.
3. The Apriori algorithm is applied to identify frequent combinations.
4. Association rules are generated and evaluated.
5. Results are displayed in tables and visual charts.



## Example Insight

A possible rule generated by the system:

2BHK + Near Metro → High Demand

This means properties with these features are frequently associated with higher buyer interest.
